undefined যার ভ্যালু এখনো বসানো বা দেওয়া হয়নি,এটা অটোমেটিক হয়।


২।
map() অ্যারের ঊপাদান নিয়ে কাজ করে,নতুন অ্যারের রিটার্ন করে।
ডাটা পরিবর্তন হয়।

forEach() লুপের জন্য ব্যবহার হয়,কিছু রিটার্ন করে না।


map() অ্যারের রিটার্ন করে।
forEach() কিছু দেয় না।

অনেক .then() হলে কোড ঝামেলা হয়।

ইরর সহজে হ্যাঁন্ডেল করা যায়।


৫।
Scope মানে ভ্যারিয়েবল কোথায় ব্যবহার করা যাবে।

Global Scope সব জায়গা থেকে access করা যায়।

Function Scope ,function এর ভিতরে declare করলে বাইরে পাওয়া যাবে না,বাইরে পাওয়া যাবে না।

Block Scope { } এর ভিতরে declare করলে বাইরে পাওয়া যাবে না,সেখানেই ব্যবহার করতে পারবে শুধু।
